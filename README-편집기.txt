# 스마트 GIF 생성기 + 편집기

## 실행 방법
1. ZIP 압축을 풉니다.
2. `10주차` 폴더에서 터미널/명령 프롬프트를 엽니다.
3. `python server.py` 실행
4. Chrome 또는 Edge에서 `http://127.0.0.1:8765` 접속

기존 GIF 생성 페이지는 유지되고 상단의 `GIF 생성기` / `GIF 편집기` 탭으로 이동합니다.

## 편집 기능
- GIF 단일 파일 업로드 및 형식 검사
- Resize (원본 기준 5%~300%, 비율 잠금)
- Crop, Downsizing, JPG/MP4(브라우저 지원에 따라 WebM) 변환
- Rotate, 좌우/상하 반전, Optimize, Reverse, Speed, Cut
- 필터, 색상 반전, 스티커/이모티콘 및 텍스트 오버레이
- 스티커/텍스트의 크기, 표시 구간, 위치 조정
- 편집 결과 미리보기 및 다운로드/파일명 설정

## 참고 및 브라우저 제약
- GIF 프레임 디코딩은 브라우저 `ImageDecoder` API를 사용하므로 최신 Chromium 기반 Chrome/Edge 사용을 권장합니다.
- 웹 브라우저 보안상 원본 GIF가 있던 폴더에 자동으로 저장할 수 없습니다. 저장 버튼은 파일명 지정 후 브라우저 다운로드를 실행합니다. 다운로드 위치는 브라우저 설정을 따릅니다.
- GIF에 이미 픽셀로 합쳐져 있는 텍스트는 원래 글자 레이어로 복원하거나 선택 삭제할 수 없습니다. 새 텍스트 오버레이는 추가할 수 있습니다.
- MP4 녹화 지원이 없는 브라우저에서는 변환 결과가 WebM이 되거나 변환을 지원하지 않을 수 있습니다.
