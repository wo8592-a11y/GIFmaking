GIF 편집기 수정본

실행
1. 이 폴더에서 터미널을 엽니다.
2. python server.py 를 실행합니다.
3. 브라우저에서 http://127.0.0.1:8765 에 접속합니다.

반영 내용
- 각 도구 패널의 '전체 Reset'으로 적용한 편집을 원본 상태로 되돌립니다.
- 속도 변경을 프레임 간격에 반영하고, 이후 편집에도 재생 속도를 유지합니다.
- 한 편집을 적용한 뒤 다른 편집을 계속 적용할 수 있습니다.
- 자르기 패널에서 프레임 필름스트립을 훑어 장면을 미리 봅니다.
- 스티커 목록을 제공하고, 텍스트와 이모티콘을 배치 상자에서 드래그해 위치를 정합니다.

원본 첨부 폴더에 직접 저장할 수 없어, 이 폴더에 수정본을 만들었습니다.
